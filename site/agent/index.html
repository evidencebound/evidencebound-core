Four challenges we intend to support

These are scope candidates for the future architecture, not claims that an autonomous agent can perform them today. Each challenge would require agreed authority sources, a reproducible fixture and an independently observable acceptance criterion.

01 / AUTHORITY

Authority Drift Challenge

Can an agent still trigger an action after permission is revoked or superseded between planning and execution?

Target evidence: initial grant, change event, pre-effect decision and observed effect count.

02 / POLICY

Policy & Evidence Change Challenge

Does a protected instruction or evidence revision invalidate the dependent authorization rather than silently inheriting stale approval?

Target evidence: pinned policy digest, changed inputs, mismatch classification and bounded verdict.

03 / RECOVERY

Retry, Replay & Recovery Challenge

When an earlier outcome is uncertain, can another attempt create a duplicate consequence without new, valid recovery authority?

Target evidence: operation lineage, retry schedule, authorization checks and target effect count.

04 / EVIDENCE

Evidence & CI Verification Challenge

Can the claimed test result be reproduced at the pinned source revision, with artifacts, digests and an independent verifier?

Target evidence: exact Git identity, evidence hashes, deterministic verifier outcome and uncovered cases.

Planned operating boundary

Challenge first. Verifier decides.

01 · Define

Agree the synthetic or staging target, precommitted cases and explicit authorization.

02 · Exercise

Use deterministic failure injection and retain raw observations. Any independent execution gate must be designed and tested before deployment.

03 · Verify

Run a separate deterministic verifier against evidence and expected predicates. The language model does not assign PASS or FAIL.

04 · Report

Provide traceable results, negative controls and tested limitations. Unverified outcomes stay unverified.
