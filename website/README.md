# EvidenceBound institutional site

Source for the compact public site intended for `https://evidencebound.org`.

The site mirrors only claims supported by the public `evidencebound-core` repository. It distinguishes the published `v0.3.0` source-release evidence from additional unreleased hardening on current `main`, and preserves explicit non-claims from the threat/security documentation.
